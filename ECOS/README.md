# 한국은행 ECOS Open API

한국은행 경제통계시스템(ECOS)의 Open API를 활용한 경제 데이터 수집 도구.

- API 문서: https://ecos.bok.or.kr/api/
- 검색 가능한 통계표: **599개**
- 응답 형식: JSON
- 최대 조회 건수: 100,000건/요청

---

## 빠른 시작

```python
from ecos_api import search, find_tables, get_stat_item_list

# 키워드로 통계표 찾기
find_tables("금리")
find_tables("환율")

# 세부 항목코드 확인
get_stat_item_list("722Y001")

# 데이터 조회
df = search("722Y001", "M", "201601", "202601", "0101000")  # 기준금리 월별
df = search("901Y009", "M", "202401", "202412", "0")        # 소비자물가지수 월별
df = search("731Y004", "M", "202401", "202412")             # 환율 월별
```

### 주기(cycle) 코드

| 코드 | 의미 |
|------|------|
| `A`  | 연간 |
| `Q`  | 분기 |
| `M`  | 월간 |
| `D`  | 일별 |

### 날짜 형식

| 주기 | 형식 | 예시 |
|------|------|------|
| 연간 | `YYYY` | `2020`, `2024` |
| 분기 | `YYYYQ#` | `2024Q1`, `2024Q4` |
| 월간 | `YYYYMM` | `202401`, `202412` |
| 일별 | `YYYYMMDD` | `20240101`, `20241231` |

---

## 제공 함수

| 함수 | 설명 |
|------|------|
| `search(stat_code, cycle, start, end, item1, item2, item3, item4)` | 통계 데이터 조회 |
| `find_tables(keyword)` | 키워드로 통계표 검색 |
| `get_stat_table_list(stat_code)` | 전체 통계표 목록 조회 |
| `get_stat_item_list(stat_code)` | 통계표 세부항목 목록 조회 |
| `get_key_stat_list()` | 100대 통계지표 조회 |
| `search_stat_word(word)` | 통계용어사전 검색 |
